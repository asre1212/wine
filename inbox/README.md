# Encrypted wine batches

Only `<UUID>.json` envelopes generated by `scripts/create-delivery.mjs` belong here.
Never commit plaintext wine lists, ratings, notes, backups, tokens, or private keys.

The receiving app decrypts in memory for review. After explicit acceptance and a successful atomic local save, it deletes the exact accepted file through GitHub's API. Failed cleanup is retried using a durable local receipt. Git history may retain encrypted blobs.

See [the assistant delivery contract](../ENTRY_HOOK.md).
