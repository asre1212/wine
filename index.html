Settings

Backup

Move between phones with two small files: a JSON backup of bottles, notes and taught voice phrases, and a separate pictures package. Import accepts either file — bring both across and your photos sync too.

Wine lists from chat

Upload a wine list in chat and ask to send it here. Review the formatted bottles below, then accept to save on this device and delete the GitHub delivery.

Connect this device

One-time setup: create a fine-grained GitHub token for asre1212/wine only, with Contents: Read and write. Paste it here, never in chat.

The token and private key stay in this browser. One receiving device at a time. Backups include saved bottles; a new device needs to reconnect and have pending batches resent.

Only encrypted deliveries pass through GitHub. After acceptance the active file is deleted; encrypted copies can remain in Git history. Your accepted bottle data stays local. Keep regular backups.

Batch add & review

Choose Wine, Sake, or Liquor, then paste one bottle per line (or separate longer entries with blank lines). Edit and review each bottle before saving.

Spreadsheet

Export the entire collection as an Excel workbook (one sheet per category).

Install

On iPhone: open this page in Safari, tap the Share icon, then "Add to Home Screen". The app then runs offline and stores data on this device.

Updates

Pulls the latest app code from GitHub and re-installs. Your bottles, pictures, ratings and notes stay safe — only the app shell is refreshed.
